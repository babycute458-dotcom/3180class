# 3180 Class 單字練習

把課堂上學到的單字記下來，用閃卡、造句、組詞和小考來練習。

## 網頁版

打開這個網址就能練習（手機、電腦都可以）：

**https://3180class.netlify.app/**

手機瀏覽器也可以用「加入主畫面」，之後像 App 一樣點開。

## 和姐姐、同學一起造句

1. 打開網頁，到「教室造句」
2. 填自己的名字（例如：姐姐、小華）
3. **只由一個人**按「建立教室」
4. 把「教室連結」傳給其他人
5. 其他人**直接點那條連結**進去，不要自己再建一間教室

兩邊頁面上的「教室代碼」要一樣，才看得到彼此的句子。
如果姐姐傳了連結給你，請用「切換過去」或直接打開她的連結，不要再按建立教室。

每人寫的句子都會留下來，不會被後來的句子蓋掉。最新一句會顯示在最上面，舊的仍可往下看。

自己的句子可以按「檢查這句」：原句會保留，另外顯示建議改寫。你也可以把建議放進輸入框，或送出「修改版」。

單字本會存在你正在用的那個瀏覽器裡。換裝置時，進度不會自動跟著走；可以用「匯出單字」備份，再在另一台「匯入 JSON」。

## 本機打開

也可以直接用瀏覽器打開 `index.html`。

## 可以做什麼

- **單字本**：新增單字、拼音、意思、詞性、課堂週次、例句
- **閃卡**：翻卡記單字
- **造句**：用這個詞寫句子並存下來
- **組詞造字**：從單字裡選一個字，組出別的詞
- **小考**：看意思選單字
